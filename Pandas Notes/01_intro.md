# Pandas

## What is Pandas?

**Pandas** is a Python library used for working with datasets.

It provides functions for:

- Analyzing data
- Cleaning data
- Exploring data
- Manipulating data

The name **"Pandas"** refers to both **"Panel Data"** and **"Python Data Analysis."**

Pandas was created by **Wes McKinney in 2008**.

---

## Why Use Pandas?

Pandas allows us to:

- Analyze large datasets
- Draw conclusions from data using statistical concepts
- Clean messy datasets
- Make data readable and relevant
- Manipulate and transform data efficiently

> **Relevant and clean data is very important in Data Science.**

---

## Data Science

**Data Science** is a branch of computer science that focuses on storing, processing, analyzing, and interpreting data to derive useful information and insights.

---

## What Can Pandas Do?

Pandas helps us get useful answers from our data.

For example:

- Is there a correlation between two or more columns?
- What is the average value?
- What is the maximum value?
- What is the minimum value?
- How many records are present?
- Are there missing or incorrect values?

Pandas can also remove rows that are not relevant or contain incorrect/missing values, such as **empty or NULL values**.

This process is called **Data Cleaning**.

---

## Key Points

| Concept | Meaning |
|---|---|
| **Pandas** | Python library for data analysis |
| **Data Analysis** | Examining data to find useful information |
| **Data Cleaning** | Fixing or removing incorrect/missing data |
| **Dataset** | A collection of related data |
| **Correlation** | Relationship between variables/columns |
| **NULL / Missing Value** | A value that is absent from the dataset |
